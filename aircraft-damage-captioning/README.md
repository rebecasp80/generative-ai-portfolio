# ✈️ Aircraft Damage Captioning

Proyecto de **clasificación y generación de subtítulos automáticos** para imágenes de aeronaves utilizando **Keras** y el modelo **BLIP**.

Este trabajo forma parte del portafolio profesional de **Ingeniería de IA generativa**, y demuestra cómo integrar modelos de visión por computador y lenguaje natural para analizar daños estructurales y generar descripciones automáticas.

---

## 🚀 Tecnologías utilizadas

- 🧠 **Modelos fundacionales** (VGG16, BLIP)
- 🐍 **Python**
- 🔬 **TensorFlow / Keras**
- 🤗 **Hugging Face Transformers**
- 📊 **Matplotlib** para visualización
- ☁️ **IBM Cloud / Jupyter Notebooks**

## 🧩 Descripción del proyecto

El modelo **VGG16** se utiliza para clasificar imágenes de aeronaves según el tipo de daño, mientras que el modelo **BLIP** genera subtítulos y resúmenes automáticos que describen el contenido visual.

Este enfoque combina **visión por computadora** y **procesamiento de lenguaje natural**, mostrando cómo los modelos multimodales pueden aplicarse en inspección técnica y mantenimiento predictivo.

---

## 🪄 Ejemplo de salida

**Subtítulo (caption):**
> A damaged aircraft with visible dents on the fuselage.

**Resumen (summary):**
